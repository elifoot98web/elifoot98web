Menu de Opções

O menu de opções ( ou ) está localizado no canto superior da tela.

Abrir 'O Matic
Selecione esta opção para abrir o nosso 'O Matic personalizado para o Elifoot 98 Online.

O Cheat 'O Matic era um programa popular no Windows 98 que permitia buscar e modificar valores na memória do jogo, facilitando alterações como dinheiro e força dos jogadores.

O programa original não é compatível com o nosso emulador, então criamos uma versão adaptada exclusiva para o Elifoot 98 Online.

Nossa versão mantém as principais funções e uma interface semelhante ao original, facilitando o uso para quem já conhece o programa.
Nota: O 'O Matic é uma ferramenta avançada. Alterações incorretas podem corromper o jogo ou causar problemas. Use com responsabilidade.

Desativar Suavização
Desativa o filtro de suavização de imagem do emulador. Caso prefira os pixels quadrados, ative esta opção.

Essa opção pode ser útil para quem está jogando em telas de baixa resolução ou dispositivos mais antigos, onde a suavização pode deixar a imagem menos legível.

 Auto-Save

Submenu com opções de salvamento de dados da máquina virtual/emulador.

Salvar Máquina Virtual

Salva o estado atual da máquina virtual, incluindo o sistema de arquivos do emulador em geral. Essa opção é útil caso você tenha feito alterações nos arquivos em geral, como a utilização do editor de equipes do Elifoot 98 ou mudanças nas configurações do Windows 3.1, por exemplo.

Desativar Sync Save

Por padrão, o sistema detecta automaticamente quando o jogo é salvo e dispara o salvamento da máquina virtual/emulador. Caso você deseje desativar essa funcionalidade, utilize esta opção.

Save Periódico (5min)

Utilize esta opção para ativar o salvamento automático da máquina virtual/emulador a cada 5 minutos.

Note que esta opção é independente da de Sync Save, ou seja, é possível ativar as duas opções ao mesmo tempo.

Dados e Backups

Este submenu oferece opções para gerenciar dados de jogos, incluindo exportação, importação e redefinição completa da máquina virtual.

Exportar Jogos Salvos

Permite baixar os jogos salvos (arquivos .e98) da máquina virtual para o seu dispositivo.
Nota: O download será feito em um arquivo compactado (.zip) contendo todos os jogos salvos.

Importar Jogos Salvos

Permite adicionar um jogo salvo de outro local (arquivo .e98) para dentro da máquina virtual.
Atenção: Caso já exista um arquivo com o mesmo nome na máquina virtual, o arquivo importado irá SUBSTITUIR o existente.

Apagar Todos os Dados

Remove todos os dados da máquina virtual, incluindo jogos salvos, configurações e outros arquivos.
Aviso: Esta ação é irreversível. Após a exclusão, os dados não poderão ser recuperados.

Input de Texto

Permite abrir uma caixa de texto para enviar conteúdo diretamente para a máquina virtual.
Essa funcionalidade é útil para colar textos do seu computador ou celular diretamente no emulador, ou para digitar caracteres que não estão disponíveis no teclado virtual.

Teclado Virtual

Ativa ou desativa o teclado virtual.

 Opções de Patch

Este submenu oferece opções para aplicação de patches para alteração de times, bandeiras, países, árbitros e demais opções dentro do jogo.

Esses patches podem ser encontrados em sites especializados, como os dos nossos amigos do Turbo Elifoot .

Carregar Patch

Permite selecionar um arquivo de patch para aplicar na máquina virtual.
Nota: Apenas arquivos ZIP com estrutura compatível com o Elifoot 98.

Remover Patch

Remove o patch atualmente aplicado na máquina virtual e restaura o jogo original.
Atenção: Jogos salvos não serão apagados, mas podem ficar em estado corrompido até que o patch seja reaplicado.

Recarregar

Recarrega a aplicação.

 Voltar ao menu

Salva o jogo, encerra o emulador e volta para a tela inicial, de onde é possível entrar em uma sala como espectador.

Se você estiver hospedando uma sala, ela será encerrada e os espectadores serão desconectados.

Multiplayer

O multiplayer do Elifoot 98 Online é um modo de assistir junto, não de jogar junto. Quem joga é sempre o anfitrião: ele transmite a tela do próprio jogo, e os convidados acompanham ao vivo, conversam pelo chat e podem apontar na tela com o cursor.

A transmissão é direta entre os navegadores (P2P). O jogo não passa por nenhum servidor nosso, e nada é gravado.

Criar uma sala

Na tela inicial, use Jogar e transmitir para amigos, ou, já dentro do jogo, o menu de opções > Hospedar Jogo Multiplayer.

Escolha um apelido, uma cor para o seu cursor e, se quiser, uma senha. O código da sala é gerado automaticamente no formato ELI-XXXX — você pode gerar outro se preferir.

Nota: o link compartilhado não inclui a senha. Se a sala tiver uma, combine-a por outro meio.

Assistir a uma sala

Na tela inicial, use Assistir a uma Partida e depois Entrar em uma sala. Cole o código ou o link que o anfitrião enviou — os dois funcionam no mesmo campo. Salas em que você já entrou aparecem ali mesmo, em Salas recentes.

Enquanto a sala está no ar

O código, o cadeado (se houver senha) e quantas pessoas estão na sala ficam visíveis na barra superior. Toque nessa indicação para copiar o link novamente.

O menu de opções passa a mostrar Sala multiplayer, que reúne o código, a lista de participantes com a qualidade da conexão de cada um, os botões de copiar e compartilhar o link, e a opção de encerrar a sala.

Chat

O chat abre pelo botão Chat sobre a tela do jogo — embaixo no modo retrato, na borda direita no modo paisagem. Ele fica ao lado (ou abaixo) do jogo sem nunca redimensionar a tela da partida.

Emoticons clássicos funcionam: :), :D, ;) e companhia viram carinhas.

Se a conexão cair

Uma queda curta não encerra mais a sala: os espectadores veem Tentando reconectar… sobre a última imagem recebida, e a transmissão costuma voltar sozinha.

Se não voltar, aparece a opção Tentar reconectar — use-a. Não é possível saber, do lado de quem assiste, se foi o anfitrião que saiu ou se foi a sua própria conexão que caiu: a sala pode continuar no ar normalmente para todos os outros.

Dica: se a conexão não se estabelecer, tente outra rede (Wi-Fi em vez de dados móveis) ou desative a VPN — a conexão direta entre navegadores é sensível a isso.

Controles Auxiliares

Os botões flutuantes de controles auxiliares são exibidos como ícones de joystick na parte inferior da tela.
Esses botões são úteis para acessar rapidamente atalhos e teclas do teclado com ações específicas para o jogo.

Em um dos botões flutuantes, você encontrará os botões F1 ao F12, A e M, utilizados para escolher táticas para a partida.
Enquanto no outro, há atalhos de teclas de navegação, como as setas direcionais e Enter .
